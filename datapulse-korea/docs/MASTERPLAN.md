## 📊 3-Layer 정보 아키텍처

```
┌─────────────────────────────────────────────┐
│         Layer 1: 지도 기반 통합 뷰          │
│    "내 위치" 중심으로 모든 데이터 통합      │
│   (부동산, 안전, 환경, 문화, 교통...)       │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│       Layer 2: 권력 & 예산 투명성           │
│   (공직자 자산, 세금 흐름, 국회 활동)       │
│    → 지역 연동: "내 선거구 국회의원"        │
└─────────────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────────────┐
│      Layer 3: 전문 분야 (교육, 의료)        │
│    특정 타겟을 위한 심화 콘텐츠             │
└─────────────────────────────────────────────┘
```

## 🎨 테마별 통합 전략

### **Hub-and-Spoke 모델**

#### Hub (중심): 지도
- 모든 데이터는 "위치" 기반으로 연결
- 예: "서울 강남구" 검색 → 12개 테마 데이터 자동 로드

#### Spoke (가지):

**🟢 Tier 1: 생활 밀착형 (항상 표시)**
- 부동산 (실거래가, 공시지가)
- 안전 (범죄율)
- 환경 (미세먼지)
- 인구 이동

**🟡 Tier 2: 투명성 (탭으로 분리)**
- 공직자 자산
- 세금/예산 집행
- 국회의원 활동

**🟠 Tier 3: 전문 영역 (별도 페이지)**
- 교육
- 의료
- 교통
- 문화

## 🛠️ 기술 아키텍처

### **Frontend**
```
Framework: Next.js 14+ (App Router)
Why?
  - SSR/SSG로 SEO 최적화
  - Cloudflare Pages 완벽 지원
  - React Server Components로 성능 최적화

UI Library:
  - Tailwind CSS (빠른 스타일링)
  - shadcn/ui (고품질 컴포넌트)
  - Framer Motion (인터랙션)

Map:
  - Kakao Map API (한국 지도 최적화)
  - Naver Map API (보조)
  - Leaflet.js (커스텀 오버레이)

Chart:
  - Chart.js (간단한 차트)
  - D3.js (복잡한 시각화)
  - Recharts (React 친화적)
```

### **Backend/Serverless**
```
Platform: Cloudflare Workers
Why?
  - 엣지에서 초고속 응답
  - 무료 티어 10만 req/day
  - KV Storage로 캐싱

Database:
  - Cloudflare D1 (SQLite 기반)
  - 공공데이터 일간 캐싱

API Strategy:
  - Workers로 공공 API 프록시
  - Rate limit 우회
  - 데이터 정제/가공
```

### **Data Pipeline**
```
┌──────────────────┐
│  공공데이터 API  │ (국토부, 경찰청, 국회...)
└────────┬─────────┘
         ↓
┌──────────────────┐
│ Cloudflare Worker│ (매일 자동 수집)
│   Cron Jobs      │
└────────┬─────────┘
         ↓
┌──────────────────┐
│   D1 Database    │ (캐싱)
│   KV Storage     │
└────────┬─────────┘
         ↓
┌──────────────────┐
│   Next.js App    │ (사용자에게 표시)
└──────────────────┘
```

    ↓

datapulse.dev (도메인 연결 - 추후)

## 🚀 단계별 구축 계획 (8주)

### **Week 1: 기반 구축**
```
✅ 목표: 프로젝트 초기 설정 완료

1. Git 저장소 생성
2. Next.js + Tailwind 프로젝트 초기화
3. Cloudflare Pages 연동 테스트
4. 지도 API 연동 (Kakao Map)
5. 기본 레이아웃 구현

산출물:
- 지도가 표시되는 기본 페이지
- GitHub → Cloudflare Pages 자동 배포
```

### **Week 2: 데이터 레이어 구축**
```
✅ 목표: 첫 번째 공공 API 연동

1. 공공데이터포털 API 키 발급 (국토부 실거래가)
2. Cloudflare Worker로 API 프록시 구현
3. D1 Database 스키마 설계
4. 데이터 캐싱 로직 구현

산출물:
- 실거래가 데이터 조회 API
- 지도에서 클릭 시 데이터 표시
```

### **Week 3-4: 핵심 기능 (Layer 1)**
```
✅ 목표: 생활 밀착 데이터 통합

테마 1: 부동산 인텔리전스
- 실거래가 히트맵
- 공시지가 vs 실거래가 비교
- 가격 추이 그래프

테마 2: 안전 지도
- 범죄 통계 API 연동
- 시간대별 범죄 히트맵
- 안전 점수 계산 알고리즘

테마 3: 환경 모니터링
- 에어코리아 API (미세먼지)
- 실시간 대기질 표시

산출물:
- "내 동네 종합 점수" 기능
- 3개 테마 통합 대시보드
```

### **Week 5: 권력 투명성 (Layer 2)**
```
✅ 목표: 임팩트 있는 기능 추가

테마: 공직자 자산 추적
- 공직윤리위 재산 공개 데이터 수집
- 지도에 공직자 부동산 표시
- "내 동네 공직자" 기능

테마: 국회의원 모니터링
- 국회 의안정보 API
- 선거구별 의원 정보
- 출석률, 발의 법안 통계

산출물:
- "내 선거구 의원은?" 기능
- 공직자 자산 지도 오버레이
```

3. 반응형 디자인
   - 모바일 최적화

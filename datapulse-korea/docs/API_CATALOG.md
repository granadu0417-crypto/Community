## 🟢 Tier 1: 필수 API (Week 2-4)

### 1️⃣ 국토교통부 - 부동산 실거래가

**API 정보**:
- 제공: 공공데이터포털
- URL: https://www.data.go.kr/data/15057511/openapi.do
- 인증: API Key
- 요청 제한: 1,000회/일
- 업데이트: 월간
- 데이터 형식: XML

**주요 데이터**:
- 아파트 실거래가
- 연립/다세대 실거래가
- 단독/다가구 실거래가
- 오피스텔 매매/전월세

**예시 응답**:
```xml
<item>
  <지역코드>11110</지역코드>
  <법정동>삼성동</법정동>
  <아파트>래미안</아파트>
  <거래금액>150,000</거래금액>
  <건축년도>2015</건축년도>
  <년>2024</년>
  <월>10</월>
  <일>15</일>
</item>
```

**활용 계획**:
- 지도에 히트맵 표시
- 시세 추이 그래프
- 주변 시세 비교

---

### 2️⃣ 경찰청 - 범죄 통계

**API 정보**:
- 제공: 경찰청 공공데이터
- URL: https://www.data.go.kr/data/15054738/openapi.do
- 인증: API Key
- 요청 제한: 1,000회/일
- 업데이트: 연간 (매년 4월)
- 데이터 형식: JSON/XML

**주요 데이터**:
- 5대 범죄 발생 건수 (살인, 강도, 강간, 절도, 폭력)
- 시도별, 시군구별 통계
- 검거율

**예시 응답**:
```json
{
  "시도": "서울",
  "시군구": "강남구",
  "살인": 3,
  "강도": 12,
  "강간": 45,
  "절도": 234,
  "폭력": 567,
  "검거율": 87.5
}
```

**활용 계획**:
- 동네별 안전 점수 계산
- 범죄 유형별 히트맵
- 연도별 추이 분석

### 3️⃣ 에어코리아 - 대기질 정보

**API 정보**:
- 제공: 한국환경공단
- URL: https://www.airkorea.or.kr/web/khaiInfo?pMENU_NO=129
- 인증: API Key (공공데이터포털)
- 요청 제한: 제한 없음
- 업데이트: 실시간 (1시간 단위)
- 데이터 형식: JSON/XML

**주요 데이터**:
- 측정소별 미세먼지(PM10), 초미세먼지(PM2.5)
- 오존, 이산화질소, 일산화탄소, 아황산가스
- 통합대기환경지수 (CAI)

**예시 응답**:
```json
{
  "stationName": "강남구",
  "dataTime": "2024-10-30 14:00",
  "pm10Value": "23",
  "pm25Value": "15",
  "pm10Grade": "1",
  "pm25Grade": "1"
}
```

**활용 계획**:
- 실시간 대기질 지도
- 산책하기 좋은 시간대 추천
- 주간/월간 대기질 리포트

## 🟡 Tier 2: 권력 투명성 API (Week 5)

### 5️⃣ 국회 의안정보 시스템

**API 정보**:
- 제공: 국회사무처
- URL: https://open.assembly.go.kr/portal/openapi/openApiDevGuide.do
- 인증: API Key
- 요청 제한: 제한 없음
- 업데이트: 실시간
- 데이터 형식: XML/JSON

**주요 데이터**:
- 의원 정보 (선거구, 정당, 약력)
- 의안 정보 (법안 제목, 발의자, 진행상태)
- 회의록
- 본회의 출석 정보

**예시 응답**:
```json
{
  "HG_NM": "홍길동",
  "ORIG_NM": "서울 강남구갑",
  "POLYNAME": "더불어민주당",
  "ELECTED_CNT": "3",
  "ATTEND_RATE": "87.5"
}
```

**활용 계획**:
- 우리 선거구 의원 정보
- 출석률, 법안 발의 수 랭킹
- 의원별 활동 점수

```typescript
  }

  async checkLimit(apiName: string): Promise<boolean> {
    // Cloudflare KV로 사용 횟수 체크
  }
}
```

### 캐싱 전략
```typescript
// 데이터 업데이트 주기에 따라 캐시 TTL 설정
const CACHE_TTL = {
  realtime: 3600,      // 1시간 (대기질)
  daily: 86400,        // 1일 (예산)
  monthly: 2592000,    // 30일 (실거래가)

}
```
